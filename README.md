# Rangefinder V1 — public preview

Static build of Rangefinder V1 (California pay-transparency checker for job advertisements), served with GitHub Pages:
https://edward-tamakloe.github.io/rangefinder-preview/

This repository contains only the compiled site. Ads are checked in the visitor's browser; nothing is uploaded, and saved check records stay in that browser.

Rangefinder flags potential issues using published rules and official sources. It is not legal advice.
